# Summary

复杂性科学在当前知识库里的意义，是把 AI 从“模型性能问题”扩展成“整体行为问题”。一旦系统进入大规模、强耦合、多模块、开放环境或多主体交互场景，局部规则与单模块解释就不再够用，必须开始讨论涌现、自组织、临界性、生态反馈和系统级后果。

## Current Understanding

- 复杂性科学最重要的不是某个具体算法，而是一种系统视角：
  - 为什么局部规则会长出整体行为
  - 为什么规模放大后会发生质变
  - 为什么少量扰动会在系统层被放大
- 对当前仓库尤其关键的是，它让以下主题能被放在同一语言里理解：
  - scaling laws
  - 涌现能力
  - 多智能体行为
  - tool / agent 生态
  - 开放环境中的反馈与约束
- 它与控制论的区别也很重要：
  - 控制论更关注反馈、稳定性和目标导向
  - 复杂性科学更关注整体行为、相变和不可局部还原性
- 因此，如果控制论帮助我们理解“闭环怎么工作”，复杂性科学帮助我们理解“闭环放大以后会长成什么样”。
