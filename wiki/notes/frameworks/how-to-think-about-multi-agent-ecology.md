# Summary

多主体系统一旦稳定存在，就不再只是“多个 agent 一起工作”，而更像一个生态：角色会分化，依赖会集中，局部竞争和协同会长期塑造整体行为。这个框架的重点不是证明多 agent 一定更强，而是判断系统是否已经进入需要按生态而非单模块思维治理的阶段。

## Confirmed Understanding

- [[complexity-science-for-ai-systems]] / [../../concepts/complexity-science-for-ai-systems.md](../../concepts/complexity-science-for-ai-systems.md) 已确认，多主体交互是复杂系统语言最直接的落点之一。
- [[game-theory-for-ai-interaction]] / [../../concepts/game-theory-for-ai-interaction.md](../../concepts/game-theory-for-ai-interaction.md) 已确认，多主体问题天然会进入互动结构与均衡问题。
- [../../../outputs/complexity-science-for-agent-ecology-2026-05-06.md](../../../outputs/complexity-science-for-agent-ecology-2026-05-06.md) 已确认，planner/executor、generator/verifier、人/agent 都可能构成最小多主体结构。

## The Core Reframe

多 agent 问题不要只问：

- “每个 agent 强不强？”

而要问：

- “这些主体长期互动后，会形成怎样的角色、依赖、瓶颈和脆弱性？”

## Four Ecological Signals

### 1. Role Differentiation

不同主体是否开始承担稳定不同的功能？

### 2. Dependency Concentration

是否出现少数关键节点承担过多流量或决策权？

### 3. Feedback Amplification

一个主体的局部错误会不会在其他主体之间循环放大？

### 4. Coordination Cost

系统改进是否开始更多受限于协调，而不是受限于单体能力？

## How To Apply

看一个多 agent system 时，优先问：

1. 当前最脆弱的节点是哪个？
2. 角色分工是显式设计的，还是隐式长出来的？
3. 多主体引入后，系统效率提升了，还是复杂度先膨胀了？

## Rule of Thumb

**一旦系统开始依赖稳定角色分工与节点协同，它就更像生态，而不再只是 workflow。**
