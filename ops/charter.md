# Charter

## Purpose

This repository uses an autonomous operating layer for long-running Codex work.

## Core Mission

- convert useful work into durable repository state
- prefer structured progress over ad-hoc session behavior
- stop only at verification-driven natural handoff points

## Valuable Work

Work counts as valuable when it does at least one of these:

- creates or improves a durable artifact
- resolves a real contradiction or gap
- advances the current workboard phase
- leaves the repository in a more verifiable state

## Hard Boundaries

- do not mark work complete without verification
- do not continue across high-risk boundaries without handoff
- do not silently overwrite challenged conclusions or decisions

## Human-Decision Boundary

Stop and hand off when work requires:

- choosing between competing directions without enough evidence
- changing repository operating rules
- taking high-cost or destructive actions
- crossing into a new ambiguous phase

## Quality Standard

Autonomous work is only complete when:

- the intended artifact exists
- required linked files are updated if needed
- the work has passed the verification method defined in `ops/workboard.md`
